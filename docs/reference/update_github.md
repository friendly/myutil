# update_github

Update installed Github packages

## Usage

``` r
update_github()
```

## Value

none

## Details

Find the local packages that were installed from Github and update them

## See also

[`installed_pkg_sources()`](https://friendly.github.io/myutil/reference/installed_pkg_sources.md),
which also lists GitHub packages
